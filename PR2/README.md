# Визуализатор графа зависимостей (Вариант №8)

CLI-инструмент на Python для анализа транзитивных зависимостей пакетов `npm`
и их визуализации с помощью `Graphviz` без использования готовых менеджеров
пакетов и сторонних библиотек.

## Основные возможности

* **Конфигурация через TOML:** загрузка и строгая валидация параметров из
  файла `config.toml` с обработкой ошибок для каждого поля.
* **Сбор данных из npm:** прямое получение манифестов пакетов по REST API
  реестра (`registry.npmjs.org`) через встроенный модуль `urllib`.
* **Итеративный обход графа (DFS):** построение графа зависимостей без
  рекурсии с учетом глубины анализа, фильтрации по подстроке и защиты от
  циклических зависимостей.
* **Тестовый режим и обратные зависимости:** работа с локальным JSON-файлом
  репозитория и поиск пакетов, зависящих от целевого (`--reverse`).
* **Визуализация в SVG:** генерация описания графа на языке `Graphviz (DOT)`
  с версиями пакетов и рендеринг векторного изображения формата `.svg`.

## Параметры и флаги запуска

* `-c, --config <путь>` — путь к файлу конфигурации TOML (`config.toml`).
* `-r, --reverse <пакет>` — вывод обратных зависимостей указанного пакета.

Параметры файла `config.toml`:

* `package_name` — имя анализируемого пакета.
* `repository` — URL-адрес реестра npm или путь к тестовому JSON-файлу.
* `test_mode` — режим работы с тестовым репозиторием (`true` / `false`).
* `package_version` — анализируемая версия пакета.
* `output_file` — имя генерируемого `.svg` файла с графом.
* `max_depth` — максимальная глубина анализа зависимостей (`>= 1`).
* `filter_substring` — подстрока для исключения пакетов из анализа.

## Установка и запуск

Требуется Python 3.11+ и системная утилита `Graphviz`:

```bash
sudo apt update
sudo apt install graphviz
```

Запуск через скрипт, `Makefile` или напрямую из командной строки:

```bash
./run.sh --config config.toml
./run.sh --config config.toml --reverse A
make test
```
