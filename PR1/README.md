# Эмулятор оболочки ОС (Вариант №8)

Графический эмулятор командной строки UNIX-подобной ОС на Python (`PyQt6`),
работающий с виртуальной файловой системой (VFS) в оперативной памяти.

## Основные возможности

* **Графический терминал:** интерактивный режим ввода-вывода с отображением
  имени подключенной VFS в заголовке окна.
* **Разбор команд:** корректная обработка аргументов в кавычках (`shlex`) и
  сообщения об ошибках (неизвестная команда, неверные аргументы, синтаксис).
* **Конфигурация запуска:** настройка пути к VFS (`--vfs`) и стартовому
  скрипту (`--script`) через аргументы командной строки с отладочным выводом.
* **Стартовые скрипты:** построчное выполнение команд с имитацией диалога и
  автоматической остановкой при первой ошибке.
* **Виртуальная ФС в памяти:** загрузка дерева файлов и папок из CSV-файла
  с содержимым в `base64`, вывод приветствия `/motd` при старте и проверка
  формата данных.

## Поддерживаемые команды

* `ls [ключи] [путь]` — вывод имени команды и переданных аргументов.
* `cd [путь]` — вывод имени команды и переданного пути.
* `vfs-save <путь>` — сохранение состояния VFS из памяти в CSV-файл.
* `exit` — закрытие эмулятора.

## Установка и запуск

Требуется Python 3.10+ и библиотека `PyQt6`:

```bash
pip install PyQt6
```

Запуск через скрипт или напрямую из командной строки:

```bash
run.bat
python src/main.py --vfs tests/vfs_deep.csv --script tests/startup_stage3.txt
```
